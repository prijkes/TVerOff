How it works

TVer's ads are stitched into the video by TVer's servers. The TVer app asks for that stitched stream with ssai=1; TVerOff makes the one request ask for the plain stream instead (ssai=0), exactly like TVer's own previews do.

To do that it places one small file inside the TVer app folder (webOSUserScripts/userScript.js) which webOS loads into TVer's pages. Nothing else on the TV is changed, and Stop Service removes the file again.

After an update of the TVer app, open TVer once: TVerOff puts its file back and restarts TVer. Over SSH: /media/developer/apps/usr/palm/applications/com.tveroff.patcher/tools/tverctl.sh status
